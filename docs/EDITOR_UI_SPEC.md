# 编辑界面 UI 规范（三端对齐用）

适用范围：iOS（参考实现）、HarmonyOS（当前实现）、Android（待改）。

本文只描述**布局与交互**，不涉及调色算法。算法与参数见 `docs/COLOR_EQUALIZER.md` 与
`crates/core/src/params.rs`。

---

## 1. 总体结构

```
┌─────────────────────────────┐
│ 状态栏 / 安全区               │
│ ┌─────────────────────────┐ │
│ │                         │ │
│ │        照片（占满）       │ │  ← 预览层：全屏、可点击、无边框
│ │                         │ │
│ │                         │ │
│ └─────────────────────────┘ │
│  预设   裁切   编辑   蒙版    │  ← 底部工具条（4 项）
├─────────────────────────────┤
│ 面板（点工具后从底部弹出）      │
└─────────────────────────────┘
```

层级（自下而上）：

| 层 | 内容 | 说明 |
| --- | --- | --- |
| L0 | 照片 | 占满可用区域，`Contain` 不裁切 |
| L1 | 叠加层 | 裁切框 / 蒙版涂抹 / 曲线网格等，与 L0 同尺寸 |
| L2 | 顶部栏 | 返回、文件名、导出、更多 |
| L3 | 底部工具条 | 预设 / 裁切 / 编辑 / 蒙版 |
| L4 | 面板 | 从底部弹出，覆盖在工具条之上（工具条仍可见） |
| L5 | 浮层 | 预设列表、对话框、Toast |

## 2. 预览层

| 项 | 规范 |
| --- | --- |
| 尺寸 | **占满屏幕可用区域**（除安全区外不留边距），不显示边框/卡片 |
| 缩放方式 | `Contain`：完整显示，比例不变，不裁切 |
| 竖屏 | 水平居中、垂直居中 |
| **横屏** | **水平居中、贴中上**：照片顶边对齐安全区下方，剩余空间留给底部工具条与面板 |
| 背景 | 纯黑 `#000000` |
| 点击 | **切换沉浸模式**（见 §5）：显示 / 隐藏其余 UI |
| 长按 | 对比原图（按住显示调整前，松手恢复） |
| 拖动 | 进入编辑面板时不响应；在裁切 / 蒙版工具下由叠加层接管 |

横屏示意：

```
┌──────────────────────────────┐
│       照片（顶边对齐）         │
│                              │
│                              │
├──────────────────────────────┤
│  预设   裁切   编辑   蒙版     │
└──────────────────────────────┘
```

## 3. 底部工具条

固定 4 项，**顺序不可变**：

```
  预设        裁切        编辑        蒙版
 ✦ 图标      ⌗ 图标      ☰ 图标      ◐ 图标
```

| 项 | 图标语义 | 打开的面板 | 备注 |
| --- | --- | --- | --- |
| 预设 | 魔棒 / 星 | 预设列表（底部面板） | 应用后可用强度滑块 0–100 |
| 裁切 | 裁剪框 | 裁切面板 | **旋转、翻转都放在这里**（见 §4.2） |
| 编辑 | 三横线滑块 | 编辑面板（分类 + 子页） | 默认打开「颜色」 |
| 蒙版 | 半圆 / 画笔 | 蒙版面板 | 画笔 / 线性 / 径向 |

交互：

- 点击未选中的工具 → 打开对应面板，该工具高亮。
- 点击已选中的工具 → 收起面板，回到纯预览。
- 面板展开时工具条**仍然可见**，高度 56pt / 52vp。
- 选中态：图标与文字用主题蓝 `#4A9EFF`；未选中 `#777777`。

> 修图（retouch）作为第 5 项属于第二阶段，iOS 已实现，鸿蒙 / 安卓暂缓。

## 4. 各工具面板

面板通用规格：

| 项 | 值 |
| --- | --- |
| 出现方式 | 从底部滑入（0.24s ease-in-out） |
| 高度 | 内容自适应，上限 = 屏幕高度 − 预览最小高度（约 40%） |
| 圆角 | 顶部 12pt |
| 背景 | `#1A1A1A`，1px 顶部描边 `#2A2A2A` |
| 把手 | 顶部 36×4 圆角条，可下拉收起 |
| 滚动 | 内容超出时内部纵向滚动，滑动时不触发预览手势 |

### 4.1 预设面板

- 列表：缩略图 + 名称，横向或两列网格。
- 应用预设 → 预览立即更新；工具条上方出现「强度」滑块（0 = 原样，100 = 完全应用）。
- 底部：「保存当前为预设」（输入名称）。

### 4.2 裁切面板（含旋转）

```
┌ 比例： 自由  1:1  4:3  16:9  3:2  原图 ┐
│         裁切叠加层（图片上）           │
│ 旋转  ⟲90°   ⟳90°   水平  -45..45°    │
│ 翻转  水平 ⇋   垂直 ⇅                 │
└        取消            应用            ┘
```

- **旋转**：
  - `⟲90°` / `⟳90°`：以 90° 为步进循环旋转（4 档回正），转的是照片数据本身。
  - `水平 -45..+45°`：微调拉直，滑块或双指旋转。
- **翻转**：水平 / 垂直镜像。
- 网格：三分线；长按可切换网格样式。
- 取消 = 恢复进入裁切前的矩形与角度；应用 = 写回参数并重渲。
- 进入裁切时**临时按未裁切状态渲染**，便于看到全图。

### 4.3 编辑面板

两行页签：

```
分类： 颜色 · 曲线 · 光学 · 细节 · 效果 · 几何      ← 可横滑
子页： 颜色 · HSL · 均衡器 · 分级 · 点颜色 · 校准 · 黑白   ← 仅「颜色」分类有
```

| 分类 | 子页 / 内容 |
| --- | --- |
| 颜色 | 颜色（色温/色调/自然饱和度/饱和度）、HSL（8 色带 × H/S/L）、均衡器（曲线图）、分级（四区色轮）、点颜色（预览取色）、校准、黑白 |
| 曲线 | RGB / 红 / 绿 / 蓝，可拖控制点，点击空白加点，双击删点 |
| 光学 | 配置文件校正、色差、晕影、几何（畸变/垂直/水平/旋转/缩放） |
| 细节 | 锐化 4 项、降噪 6 项 |
| 效果 | 纹理 / 清晰度 / 去雾、暗角 3 项、颗粒 3 项 |
| 几何 | 畸变 / 垂直 / 水平 / 旋转 / 缩放 |

滑块规格：

- 行高 40，左标签 64–76 宽、右数值 40 宽，中间滑轨。
- 双击滑块复位到中性值；拖动时面板其余行淡出、顶部显示大号数值。

均衡器曲线图：

- 彩色色相背景 + 512 点曲线 + 8 个可拖节点 + 底部色相条。
- 节点等距 45°，整体可旋转（节点旋转 ±23°）。
- **双击节点复位**（色相 0°、增益 1.0）。
- 0° 节点在左右两端各显示一半（周期闭合）。

### 4.4 蒙版面板

```
类型： 画笔   线性   径向          叠加显示 ●
列表： [ 蒙版 1 ] [ 蒙版 2 ] + 删除
画笔： 大小 ——●——  擦除 ○
```

- 画笔：在预览上涂抹，叠加层红色表示区域、蓝色表示擦除。
- 线性：预览上拖出方向（起点→终点），叠加层画连线 + 两端手柄。
- 径向：按下确定中心、拖动确定半径，叠加层画椭圆。
- **蒙版内调整复用编辑面板**：选中蒙版后，编辑面板的所有滑块只作用于该蒙版；
  退出蒙版工具恢复全局参数。

## 5. 沉浸模式

- 触发：**点击照片**。
- 效果：隐藏顶部栏、底部工具条、当前面板；只留照片。
- 退出：再点一次照片，或从屏幕边缘上滑。
- 沉浸中不响应面板手势；若正在裁切/蒙版涂抹，点击属于叠加层，不触发沉浸。

## 7. 状态与持久化

- 每张照片的编辑参数按 **uri 哈希**存本地（iOS：`EditStore`；鸿蒙：`fdxmp_edits`）。
- 存的内容：全部调色参数 + 裁切矩形 + 旋转档位 + 蒙版（含各自 adjustments）+ 点颜色样本。
- 保存时机：返回、导出成功、页面销毁；建议加 3s 防抖自动保存。
- 导出设置（格式 / 质量）单独存（`fdxmp_export`）。

## 9. 验收清单

- [ ] 照片占满屏幕，竖屏居中、横屏贴中上。
- [ ] 底部 4 项工具顺序为 预设 / 裁切 / 编辑 / 蒙版。
- [ ] 旋转（90° 步进 + 微调）与翻转都在裁切面板内。
- [ ] 点击照片隐藏全部 UI，再点恢复；裁切/蒙版进行中不触发。
- [ ] 切换工具时面板正确替换，工具条选中态正确。
- [ ] 面板高度不挤压预览到 40% 以下。
- [ ] 每张照片的参数可恢复（含旋转档位、蒙版、裁剪）。
