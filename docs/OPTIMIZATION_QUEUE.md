- [x] 1.3.7 阴影重做（实拍反馈：阴影 +100 画面"发灰"，与 Lightroom 差距明显）：
      - 根因：旧实现是**显示域加法**（`sh * w_sh * (0.55 - s) * 0.30`，最深像素加得最多）——
        纯黑被垫成 ~42/255 的灰（全图暗部加一层灰底），且三通道等量相加 → 暗部去色变中性灰；
      - 新实现：曝光式**乘性**增益（掩膜 `0.03→0.33` 淡出；+100 深暗部 ≈ +2EV，
        -100 ≈ -1.2EV）——纯黑保持纯黑、通道比例不变（暗部颜色不掉）；
      - 实拍取样对照（同一照片，阴影 +100）：门洞暗部 (5,6,6) → 新 (18,21,21)
        （LR 实测 (21,26,24)，旧 (44,44,45)）；裙摆 (21,25,31) → 新 (44,51,61)
