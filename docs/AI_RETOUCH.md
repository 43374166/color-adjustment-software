# AI 修图（v1.6.0：接入 LaMa / GFPGAN / Real-ESRGAN，iOS 优先）

日期：2026-10-13
范围：Rust 核心 `fdxmp-core::retouch` + FFI + iOS（项目制 / 一键修图 / 同步）。
原则：**修图与调色分开**（修图只改像素，调色仍走既有渲染管线），可随时切 Tab 交替使用。

## 0. v1.6.0：AI 模型链

流程：`原图 → 人像解析（BiSeNet / Vision）→ 问题检测（瑕疵区域）→ 全局校正（调色）→
局部修复（LaMa）→ 增强（GFPGAN）→ 皮肤美化（频率分离磨皮）→ 肤色统一（特定色映射）→
五官/几何塑形（FaceMesh / Vision 关节）→ 羽化融合 → 输出（可选 Real-ESRGAN 超分）`。

| 阶段 | 模型 / 实现 | 文件（大小 / 许可证） | 说明 |
| --- | --- | --- | --- |
| 局部修复 | **LaMa**（big-lama ONNX，512 固定画布） | `inpaint_lama_fp32.onnx`（208 MB，Apache-2.0） | 皮肤内检测「比周围暗」的斑点 → 区域 + 48px 上下文裁剪（相邻区域贪心打包进 ≤512 画布）→ 重绘 → 软权重羽化融合；模型缺失时退经典软阈值去瑕疵 |
| 人脸增强 | **GFPGAN v1.4** | `face_restore_gfpgan14_fp32.onnx`（340 MB，MIT；权重 Apache-2.0） | 最大人脸 5 点对齐 → 512 裁剪恢复清晰度 / 五官 → 仿射逆映射回贴，按面部蒙版羽化（锐度不足处自然过渡）；`restore` 强度 0..100 线性混入，缓存按图指纹失效 |
| 导出增强 | **Real-ESRGAN 紧凑版**（自转，动态尺寸） | `superres_realesrgan_x4v3_fp32.onnx`（4.9 MB，BSD-3-Clause） | 以 4× 逐块（256，重叠 16 线性融合）推理，再按「目标最长边」逐块缩放拼接；输入 ≤4096、输出 ≤64 MP；导出弹框「高清增强（×2 超分）」开关 |
| 身体塑形 | **iOS Vision** 身体 19 关节（肩→髋躯干轴） | 系统框架（0 MB） | 腰腹带高斯权重向中轴收形，横向按人像蒙版羽化；无姿态时退回轮廓剖面 |
| 脸部塑形 | MediaPipe FaceMesh 478 点；**Vision 人脸关键点回退** | 见 §2 | 瘦脸 / 下巴 / 大眼 / 瘦鼻；Vision 只在 FaceMesh 缺失时使用 |

工程要点：

- 全部推理在 Rust 核心（`smartmask/onnx_retouch.rs`，`ModelSpec` 配置驱动：路径 / SHA-256 /
  归一化 / 输入尺寸 / 许可证全部来自注册表，换模型只改配置）；
- AI 结果按「图像指纹」缓存（修复图 / 增强图只算一次），滑杆强度只是线性混入；
- UI 通过 `fdxmp_retouch_progress` 轮询阶段文案（「AI 人脸增强…」/「AI 修复瑕疵…」等）；
- 模型缺失 / 失败自动降级：LaMa→经典去瑕疵、GFPGAN→跳过、ESRGAN→原尺寸导出。

## 1. 能力

| 功能 | 实现 |
| --- | --- |
| 一键修图 | 识别（五官 478 点 + 蒙版）→ 去瑕疵 → 低 / 中 / 高频磨皮 → 统一肤色 → 脸部塑形 → 身体塑形；全程加载动画 |
| 去瑕疵 | 皮肤蒙版内「比周围暗」的高频异常（痘印 / 斑点）软阈值收敛，两轮迭代，保留毛孔与边缘 |
| 低 / 中 / 高频磨皮 | 三级频率分离：低频（光影 / 肤色不均）再平滑、中频（纹理）按皮肤权重衰减、高频（毛孔 / 噪点）按强度衰减；皮肤蒙版先柔化，避免边界硬边 |
| 统一肤色 | 肤色区 Cb / Cr 大半径平滑 + 向肤色中位数收敛（改善泛红 / 斑驳）；Y 保持不变 |
| 脸部塑形 | MediaPipe FaceMesh 478 点驱动：瘦脸（下颌收拢）/ 下巴（拉长收窄）/ 大眼（虹膜径向放大）/ 瘦鼻（鼻翼收拢） |
| 身体塑形 | 人像蒙版逐行轮廓（竖直平滑）→ 腰腹带（42%..72% 身高）两侧向中轴收形；中轴不动、轮廓外 35% 过渡归零（无硬接缝） |

参数（0..100，缺省 0）：`blemish / smooth_low / smooth_mid / smooth_high / skin_tone /`
`face_slim / chin / eye_enlarge / nose_slim / body_slim` —— 存在 `EditParams.retouch`，
与调色一起随编辑记录保存 / 同步。

## 手动修图工具（v1.5.1 新增）

修图 Tab 分三个子模式：

- **美颜**：一键修图 + 手动预设（自然 / 精致 / 质感 / 清透，即"一键美颜"）+ 参数滑杆；
- **污点**：手动祛痘笔——点按 / 轻拖瑕疵处，核心用环形中位数把瑕疵盖住（`fdxmp_heal_apply`，
  纯算法）；支持撤销上一个 / 清空；
- **液化**：拖动推挤像素（`fdxmp_liquify_apply`，位移场逆映射 + 双线性采样，纯算法）；
  半径 / 强度可调，笔画可撤销。

手动工具链：`原图 → 污点修复 → 液化 → 修图参数（磨皮等）→ 显示/导出`，
撤销按"重建链条"实现（点列表 / 笔画列表重放）。

关键点映射：SCRFD 检出 → ArcFace 5 点对齐 → FaceMesh 跑对齐裁剪 → 仿射逆变换回原图坐标。
模型随 IPA 打包（CI `shasum` 校验），加载前核心再校验一次 SHA-256；
缺失时只退化「脸部塑形」（磨皮 / 肤色 / 瘦身仍可用），面板会提示。

## 3. iOS 交互

- **项目制**：编辑 Tab 右上「＋」→ 系统多选（PHPicker）→ 自动创建项目并进入；
  项目列表显示项目内照片数量；长按可重命名 / 删除（照片保留在图库）。
  项目内只显示添加的那几张照片。
- **左右切换**：仅项目内可左右滑动切换照片（带淡入 + 加载动画）；
  设备 / 最近编辑单张编辑取消左右切换。
- **一键同步**：仅项目内显示「同步」菜单：同步调色 + 修图 / 仅修图 / 仅调色
  （裁切与蒙版笔迹是每张照片自己的构图，保持不动）。设备单张编辑没有同步。
- **基础调色**：进入项目内的照片且没有编辑记录时，自动按图像统计做一版温和基调
  （灰度世界白平衡 + 中位亮度曝光 + 少量对比 / 阴影 / 自然饱和度），避免原片 / RAW 发灰；
  用户改动后才写编辑记录。
- **修图 Tab**：一键修图（全屏阶段动画：识别五官 → 去瑕疵 → 磨皮 → 肤色 → 塑形）+
  三组滑杆（皮肤 / 脸部塑形 / 身体塑形）+ 重置修图；滑杆拖动 0.35s 防抖重算，松手立即重算。

## 4. 性能与边界

- 修图在 **代理分辨率**（≤2048 长边）上进行；960×1444 实测约 1.4s（release，Windows CPU），
  iPhone 同量级；同图多次调参复用识别结果（核心按图像指纹缓存蒙版 / 关键点）。
- 导出：开启修图时先在导出分辨率上应用修图再走调色；超过 4096 长边时降采样应用后上采样
  （保内存；修图主要作用于皮肤，损失可接受）。
- 修图开启时 1:1 区域细节帧自动回退整帧细节帧（区域帧来自未修图全分辨率源，避免观感不一致）。
- Windows / Android / HarmonyOS 端 FFI 已就位（`fdxmp_retouch_analyze` / `fdxmp_retouch_apply`），
  本轮只在 iOS 接入 UI。
