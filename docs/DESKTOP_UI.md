## 0. 为什么 Windows 不用三大 Tab

规格中的「移动端软件流程 / 三大 Tab（设备 / 编辑 / 我的）」是**移动端专属**约束，
对应 Lightroom Mobile 的交互；把它照搬到 Windows 会浪费桌面端的关键优势：
大屏、鼠标（滚轮 / 悬停 / 双击）、键盘快捷键、多面板并列、原生文件对话框、
拖放、多窗口与多显示器。

因此：

| 端 | 交互范式 | 依据 |
| --- | --- | --- |
| Windows | Lightroom **Classic** 式桌面布局（本文件） | 桌面优势：多面板 / 快捷键 / 多窗口 |
| Android / HarmonyOS / iOS | Lightroom Mobile 式三 Tab + 底部弹出面板 | `docs/SPEC.md` 移动端流程（严格执行） |

两端的**功能集合完全一致**（15 项调色、曲线、HSL、颜色分级、细节、镜头、变换、
裁剪、蒙版、预设、历史、导出），差异只在呈现与操作方式；`fdxmp-core` 与
`.fdxmp` 预设四端共用。

## 2. 桌面专属能力

已实现（阶段 0 骨架）：

- **面板可拖动改变宽度、可整块隐藏**：左右栏与胶片条都是 resizable panel；
  `视图` 菜单可开关，`Tab` 一键隐藏/恢复全部面板（沉浸看图）。
- **快捷键**：`Ctrl+Z` 撤销、`Ctrl+Y` / `Ctrl+Shift+Z` 重做、
  `←` `→` 切换照片、`Tab` 面板开关；滑块双击复位。
- **鼠标**：滚轮在画布上缩放（5%–800%），`视图 → 适应窗口 / 100%`。
- **原生文件对话框**：`文件 → 导入图片…`（rfd，带 RAW / HEIC / 常见格式过滤器）。
- **拖放导入**：把文件拖进窗口即加入目录与胶片条。
- **历史面板跳转**：点击任意历史步骤直接回到该状态（`Engine::jump_to`）。
- **窗口状态**：默认 1440×900，最小 1024×640，可自由缩放。

路线图（阶段 6 展开）：

- 多窗口 / 第二显示器：参考图窗口、网格审阅窗口、编辑窗口分离；
- 右键上下文菜单（胶片条、目录、历史项）；
- 面板布局预设（紧凑 / 审阅 / 修图）与布局持久化；
- 快捷键自定义（完整 Lightroom 兼容键位表）；
- 画布叠加：构图网格、参考线、前后对比（\ 键）、分屏对比；
- 大图性能：GPU 分块渲染 + 代理图，保证 24MP 全分辨率 ≥ 30fps。
