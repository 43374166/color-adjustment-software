# 局部蒙版模块（v0.4.0）

日期：2026-10-10
范围：iOS 蒙版编辑器 + Rust 核心蒙版系统（首期三种：**线性渐变 / 径向渐变 / 画笔**）

蒙版不是滤镜，而是**局部调整的作用区域**：每个蒙版挂一组局部调色参数，
只影响蒙版 alpha 覆盖的区域；多个蒙版可叠加，按列表顺序依次合成。

## 1. 数据模型

蒙版保存在 `EditParams.masks[]`（Rust `params::MaskParams`，iOS `MaskUi`），
所有几何参数都是**归一化坐标**（相对原图，不随屏幕缩放变化）：

| 字段 | 说明 |
| --- | --- |
| `id` / `name` | 稳定标识与显示名称（重命名只改 `name`） |
| `kind.type` | `linear_gradient` / `radial_gradient` / `brush` |
| `visible` | 显示 / 隐藏（隐藏的蒙版不参与渲染，也不产生叠加） |
| `inverted` / `opacity` / `feather` | 通用属性（`feather` 为 v0.3 遗留的整体模糊羽化） |
| `kind.data` | 几何参数或笔迹 |
| `adjustments` | 该蒙版独立的 light / color / effects 调色参数 |

几何参数：

- **线性渐变**：`start` / `end` 是过渡带两条边界线的锚点（100% 与 0% 一侧），
  50% 中心线过两点中点；拖动端点旋转、拖动中心线平移、拖黄色手柄**只移动被抓住的那条
  边界线**（两条线独立），`过渡` 滑块按中心对称改带宽度。
  三条线的方向 = 归一化空间垂线在屏幕空间的像，与实际过渡方向严格一致。
- **径向渐变**：`center` / `radii[x,y]` / `rotation` / `inner`；
  内圈（实线，100%）与外圈（虚线，0%）之间是 smoothstep 过渡，
  `inner`（由 UI 的 `羽化` 映射：`inner = 1 - 羽化/100`）即内圈相对外圈的缩放。
  旋转定义在**像素等比空间**（`radii × 图像尺寸` 后旋转），屏幕上是标准旋转椭圆。
  拖外圈手柄改半径时内圈按 35% 跟随，拖内圈手柄直接调羽化。
- **画笔**：`strokes[]`，每条笔画保存**点序列 + 落笔参数快照（size / feather / flow / density）+ 擦除标记**；
  改面板参数只影响之后的笔画，已画好的笔画保持原样。v0.3 的纯点数组格式仍可解析
  （自动升级为一条普通笔画）。

## 2. 渲染（Rust 核心）

- **线性**：按到中心线的有符号距离做 `smoothstep`（边界处 100% / 0%，中心线 50%）。
- **径向**：按椭圆距离 `sqrt((x/rx)^2 + (y/ry)^2)` 在 `[inner, 1]` 上做 `smoothstep`。
- **画笔**：离屏栅格 + **径向渐变 stamp 累积**；折线按 `半径 × 0.25` 间距盖印，
  同一笔内 `a += (1-a)·coverage·flow`，单笔上限由 `density` 封顶；
  擦除笔画反向混合 `a *= 1 - coverage·flow`。stamp 只遍历包围盒，逐行 rayon 并行。
- 统一后处理：反向 → 不透明度 → 遗留羽化（可分离盒式模糊）。
- 栅格分辨率：`clamp(长边 / 2, 512, 2048)`（预览快、导出细），
  权重栅格按 `mask_key`（几何 + 可见性 + 反向 / 不透明度 / 羽化 + 尺寸）缓存，
  拖动局部调色滑块不会触发栅格重建。
- 合成顺序：原图 → 全局调整 → 每个可见蒙版按顺序应用局部调整
  （GPU 路径 `gpu_pipeline.rs` 与 CPU 预览 `preview.rs` 一致）。

## 3. 交互（iOS，对标 Lightroom Mobile）

- 底部工具栏「蒙版」入口；面板自下而上：蒙版列表（缩略图 / 名称 / 显示隐藏 / 长按重命名·
  复制·删除）+ 新建 + 完成 → 通用操作（反转 / 重置 / 叠加 / 复制 / 重命名 / 删除）→
  参数 → `蒙版`（形状参数）/ `调整`（局部调色）两个子页（最上，可切换）。
- 面板通用布局：参数在上、导航在下 —— 编辑页自下而上为「工具条 → 亮度/颜色/效果/细节/曲线
  分类导航 → 参数 → 颜色/HSL/分级等子页标签」；曲线与蒙版工具下顶部栏、底部工具条一并隐藏
  （把空间让给编辑区），蒙版用面板内的「完成」返回编辑，曲线用分类导航切走。
- 分类导航：点同一个分类两次 = 参数面板从下往上展开 / 收起（面板高度带过渡动画）；
  长按分类 0.5s = 临时把该分类参数归零（颜色分类含 HSL 与分级），松手恢复，
  用来单独对比这个分类的调色变化（与「长按照片 0.5s 看原图」同款手感）。
- 子页标签（颜色/HSL/分级、效果/晕影/颗粒、锐化/降噪）字号加大并居中。
- 曲线：进入后分类导航整排隐藏，只留一个「完成」按钮；点「完成」回到进入曲线前的分类。
- 竖屏调色：面板浮在整图上（图片保持铺满、不被挤小），面板背景微微透明；
  横向拖动任一滑块时（点击步进不算）隐藏所有 UI，只留这一个滑块（Lightroom 做法），
  蒙版 / 裁切 / 横屏仍保持推挤布局以保证整图可操作。

## 0.6.0 细节批（手感 / 预览 / 直方图 / 预设强度）

- 触觉反馈：滑块跨中性点与点击步进、归零、画笔落笔、曲线加点删点、展开收起是轻/选择感；
  长按对比（看原图 / 分类归零）是中击；进入编辑页与蒙版前预热 Taptic Engine。
- 沉浸拖动时画面顶部显示大号数值浮层（标签 + 数值，缓动淡入）。
- 沉浸拖动（滑块）也走 720 低分辨率快速缓冲，松手回全分辨率。
- 直方图：点一下切换 RGB / 亮度 / 单通道；左上蓝三角 = 阴影剪裁、右上红三角 = 高光剪裁
  （含占比百分比），长按 0.5s 显示 / 隐藏剪裁警告；直方图上的长按不再触发"看原图"。
- 预设强度：应用预设后出现「强度」滑块，0 = 应用前、100 = 预设原样，
  曲线按 50% 分界切换（与核心 `EditParams::blend` 一致）；做其它编辑后该上下文自动失效。

## 0.7.0 细节批（微调 / 历史 / 对比 / 细节帧）

- 长按滑块 0.4s 进入**微调**：拖动速度降到 1/5，用于精细对数值（松手正常提交）。
- 撤销 / 重做带操作名：撤销后提示「已撤销：曝光度」，长按撤销键弹出**历史列表**，
  可一次回退多步（列表按"撤销「操作名」· 回退 N 步"显示）。
- 分屏对比：顶栏开关进入 before/after 模式，左原图（保留裁切、全部调整归零）右调色，
  分割线可拖；切工具自动退出。
- 放大细节帧按缩放级别动态取分辨率（视口像素 × 缩放 × 1.15，1200..4096）：
  不再一律 4096，2.5x 时内存峰值从约 64MB 降到约 36MB。
  真正的"按视口分块"需要核心支持帧外坐标（暗角 / 颗粒按整帧计算），留到核心批。
- 渲染失败自动降一档分辨率重试一次，不再直接弹错误。

## 0.8.0 细节批（裁切 / 导出 / 数据 / 蒙版）

- 裁切：构图网格可切换（关 / 三分 / 网格 / 对角 / 黄金比例，随参数保存）；
  拖出边界有 5% 阻尼越界，松手 160ms 缓动回弹并轻震。
- 导出：「我的」页可选格式（JPEG / PNG / HEIC）、JPEG 质量（50–100%）、
  保留 EXIF / GPS 拍摄信息（含颜色配置）、导出完成后分享；
  顶栏导出按钮显示百分比进度。
- 数据：编辑记录从 UserDefaults 迁到 `Application Support/fdxmp/edits/*.json`（原子写，
  旧记录读取时自动迁移）；画笔坐标量化到 3 位小数，缩小项目 JSON 体积。
- 蒙版：调整页分类支持长按归零对比；蒙版卡片菜单新增「复制设置 / 粘贴设置」
  （同类型连形状一起套用，不同类型只套用局部调整）；抬笔后保留笔刷光标。

## 0.9.0 细节批（预设 / HSL / 分级 / 蒙版叠加色）

- 预设面板改为**缩略图网格**：用当前照片（含当前裁切）小图渲染每个内置预设的效果，
  进入预设工具时后台刷新，选中的预设高亮描边。
- HSL 面板：横向**色相彩虹条**（8 色带刻度）——点或拖直接选色带，右侧显示当前色带名。
- 颜色分级：新增**色相 / 饱和度色轮**（角度 = 色相、半径 = 饱和度，中心 = 中性），
  与 色相 / 饱和度 滑块联动，拖动时实时预览、松手记一步历史。
- 蒙版叠加颜色可选（红 / 绿 / 蓝 / 白 / 黑，与核心 `OverlayColor` 对齐）：
  画布叠加与列表缩略图同步换色，随参数保存。

## 1.0.0：帧外坐标与放大 1:1 区域渲染

- 核心新增**帧外坐标**（`FrameOrigin`）：管线的暗角 / 颗粒与蒙版都能按"这段像素在整帧里的位置"
  计算；`apply_masks_at` / `render_preview_image_at` 供区域渲染复用，
  整帧渲染结果与区域渲染**逐像素一致**（测试 `region_render_matches_full_render` 逐像素断言）。
- 新增区域渲染入口：核心 `render_memory_rgba_region` + FFI `fdxmp_render_region_rgba`——
  只渲染可见矩形（向外带余量），细节模糊在区域内做、其余按整帧坐标；
  要求几何 / 镜头为单位变换、蒙版不依赖图像内容，否则报错由调用方回退整帧渲染。
- iOS：放大到 2.5x 以上且无裁切 / 旋转时，走**区域 1:1 细节帧**——
  按可见范围请求源图（上限原图长边、≤2400 万像素），裁出区域 + 余量交给核心，
  结果按归一化矩形对齐贴回预览（平移去抖 180ms、不覆盖可见范围就不显示，避免接缝）；
  不满足条件时自动回退原来的整帧细节帧（动态分辨率 1200–4096）。
- 画布控件：线性显示中心线（虚线）+ 两个旋转端点 + 两条过渡边界 + 黄色羽化手柄；
  径向显示外圈、内圈（虚线）、中心点、四向缩放白点、四向羽化黄点、顶部旋转手柄。
- 手势：单指操作蒙版控件（画笔模式为涂抹 / 擦除）；双指缩放 / 平移画布，
  线性与径向支持双指旋转（旋转手柄同效）。第二指落下会中断单指操作。
- 蒙版叠加：红色半透明覆盖为**真实 alpha**（FFI `fdxmp_mask_overlay_rgba`，
  与预览渲染共用栅格缓存），可开关；隐藏蒙版叠加为空。
- 进入「调整」子页自动收起红色叠加（调色时只看效果），回到「蒙版」子页恢复原状态；
  叠加收起期间不生成大图叠加，只留列表缩略图。
- 拖动 / 涂抹期间用低分辨率缓冲（长边 720）渲染，松手后回到全分辨率预览。

## 4. 撤销与持久化

- 撤销重做覆盖：新建、删除、复制、重命名、显示隐藏、反转、重置、参数改变、
  一次完整拖动、**一笔画笔**（含擦除）。画布操作起点记快照、松手提交一步；
  画布拖动过程与中间渲染不写历史。
- 保存：编辑状态序列化为 `EditParams` JSON 存在相册资源上，重开项目后
  蒙版参数与笔迹逐点一致（旧 v0.3 数据可直接升级读取）。

## 5. FFI

```c
uint8_t *fdxmp_mask_overlay_rgba(const char *params_json,
                                 const char *mask_id,
                                 uint32_t width,
                                 uint32_t height,
                                 uint32_t *out_width,
                                 uint32_t *out_height,
                                 size_t *out_len);
```

返回「8 字节大端宽高 + 预乘 RGBA8」缓冲区（红色半透明叠加），
用于画布蒙版叠加与列表缩略图；只支持几何型蒙版（画笔 / 线性 / 径向）。
