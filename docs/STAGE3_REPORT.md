# 阶段 3 报告：蒙版系统

日期：2026-10-03
范围：画笔 / 线性渐变 / 径向渐变 / 颜色范围 / 亮度范围 + GPU 局部调整 + 蒙版 UI
（AI 蒙版按规格只做接口与入口占位，模型在阶段 7 集成）

## 1. 已完成

### 1.1 蒙版生成器（`crates/core/src/masks.rs`）

| 类型 | 实现 |
| --- | --- |
| 画笔 Brush | 笔画折线 + 圆形笔刷（大小/羽化/流动/密度）；按笔画包围盒裁剪，rayon 行并行 |
| 线性渐变 | 起点权重 1 → 终点 0，沿渐变轴投影 |
| 径向渐变 | 椭圆 + 旋转，中心 1 → 边缘平滑衰减 |
| 颜色范围 | RGB 距离 + 范围/平滑度阈值（0..1 归一化） |
| 亮度范围 | Rec.709 亮度区间 + 平滑过渡 |
| 深度范围 | 预留（返回明确提示，需要深度图） |
| AI 蒙版 | 主体 / 天空 / 背景 / 人物 / 物体 —— 接口就绪，模型阶段 7 集成 |

统一后处理：反向、不透明度、羽化（可分离盒式模糊，半径随羽化百分比缩放）。
权重栅格为 `MaskRaster { width, height, weights: Vec<f32> }`，GPU 与 UI 叠加层共用。

### 1.2 GPU 局部调整（`shaders/color_pipeline.wgsl` + `blur.wgsl`）

- 着色器拆分：`blur.wgsl`（可分离模糊）与 `color_pipeline.wgsl`（主调色 + 拷贝），
  避免绑定冲突并保持各自可读。
- `cs_main` 双模式：`p(68)=0` 全局调色；`p(68)=1` 时用该蒙版参数重跑管线，
  再按 `R32Float` 权重纹理把局部结果**在线性空间**混入当前图像。
- ping-pong：A → B → A → B…；蒙版趟数为奇数时用 `cs_copy` 把结果搬回显示纹理，
  保证注册给 egui 的纹理始终有效。
- 蒙版权重纹理按**内容哈希**（`masks::mask_key`）缓存：参数不变不重新生成，
  画笔画一笔只有包围盒范围重算。
- 引擎每帧只 dispatch 变化的趟次；无蒙版时零额外开销。

### 1.3 蒙版 UI（Windows）

- 右栏「蒙版」面板：创建 画笔 / 线性 / 径向 / 颜色范围 / 亮度范围；
  AI 五个入口以禁用按钮呈现（悬停提示"阶段 7 接入"）。
- 蒙版列表：选中 / 复制 / 删除；选中后右栏顶部显示"正在编辑蒙版：xxx"与「返回全局」。
- 蒙版参数：反向 / 不透明度 / 羽化 / 叠加显示开关 + 类型相关参数
  （画笔大小·羽化·流动·密度、渐变端点或中心半径、颜色/亮度范围阈值）。
- **编辑目标切换**：调色 / 曲线 / HSL / 颜色分级 / 细节面板统一作用于
  "当前编辑目标"（全局或某个蒙版），无需两套 UI。
- **画笔在画布上直接绘制**：按住左键拖动即追加笔画点（归一化坐标），
  实时重算蒙版；「清除笔画」一键清空。
- **蒙版叠加显示**：半透明彩色覆盖（红/绿/蓝/白/黑可选），CPU 生成 + 内容哈希缓存。

## 4. 遗留问题（阶段 4/5/7 输入）

1. **AI 蒙版**：入口与数据结构就绪，模型推理在阶段 7（ONNX Runtime / Core ML / LiteRT / XEngine）。
2. **深度范围**：需要深度图来源（移动端人像模式），接口已预留。
3. **画笔点抽稀**：当前每个鼠标帧都追加一个点，快速涂抹时点较多；
   阶段 7 做距离阈值抽稀 + 笔压/速度模拟。
4. **蒙版叠加**为 CPU 生成（2.8MP 约 10-30ms，内容哈希缓存），
   阶段 7 可改为 GPU 直接绘制权重纹理。

## 5. 结论

阶段 3 目标达成：五类蒙版（画笔 / 线性 / 径向 / 颜色范围 / 亮度范围）全部可用，
GPU 局部调整在线性空间混合、ping-pong 输出稳定，蒙版 UI 与全局调色面板共用同一套控件，
画笔可直接在画布上涂抹并实时看到效果。AI 蒙版按规格留待阶段 7 集成模型。
可以进入阶段 4（预设与导出：XMP 导入、.fdxmp 应用、导出管线）。
