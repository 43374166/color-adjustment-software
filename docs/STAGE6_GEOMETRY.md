# 阶段 6 报告：几何管线（裁剪 / 旋转 / 翻转 / 透视）与细节从属参数

日期：2026-10-03　对应自主计划 P1 / P2。

## 1. 交付内容

### 1.1 几何管线（P1）

| 模块 | 位置 | 说明 |
| --- | --- | --- |
| 几何数学 / CPU 参考 | `crates/core/src/geometry.rs` | 3×3 逆映射矩阵（旋转 / 翻转 / 透视 / 裁剪）、双线性重采样（线性光）、裁剪尺寸、比例换算、旋转约束（自动构图） |
| GPU 几何趟 | `crates/core/src/shaders/geometry.wgsl` | `cs_geometry`：输出像素 → 逆矩阵 → 源图双线性采样（rgba8-srgb → rgba16f） |
| 管线集成 | `crates/core/src/gpu_pipeline.rs` | 渲染目标按裁剪尺寸缓存重建；恒等几何走快速路径（无额外开销）；蒙版按逆映射回源图坐标采样 |
| 桌面裁剪模式 | `crates/win_ui/src/main.rs` | 对标 Lightroom 的独立裁剪视图：全幅 + 四周压暗 + 角/边手柄 + 网格（三分 / 网格 / 对角 / 三角 / 黄金 / 无）+ 比例（自由 / 1:1 / 4:3 / 3:2 / 16:9 / 原始）+ 框外拖拽摆正 + 水平/垂直翻转 + 自动构图 + 重置 / 完成 |
| 变换面板 | `crates/win_ui/src/main.rs` | 垂直/水平透视、旋转、翻转、重置，实时预览 |
| 导出 | `crates/win_ui/src/main.rs` | 代理导出与全分辨率导出都按裁剪后的画面输出 |

### 1.2 细节从属参数（P2）

全部参数进入着色器计算：

- 锐化：数量、半径（第二套小半径模糊）、细节（高频/中频混合）、蒙版（局部梯度自适应）；
- 降噪：亮度、亮度细节、亮度对比度、颜色、颜色细节、颜色平滑度；
- 惰性调度：锐化与亮度降噪都关闭时不产生任何额外 dispatch，默认参数输出与旧版逐像素一致。

## 3. 性能（debug 构建，GTX 1050 Ti / Vulkan，2048×1365 代理）

| 场景 | 平均帧时间 | 帧率 |
| --- | --- | --- |
| 全参数调色（含两趟模糊） | 5.5 ms | ~181 fps |
| +2 个蒙版 | 10.3 ms | ~98 fps |
| 旋转 5° + 裁剪 80% | 3.9 ms | ~259 fps |
| 细节全开（锐化半径/细节/蒙版 + 亮度/颜色降噪） | 7.2 ms | ~139 fps |

结论：几何趟开销低于 1 ms（裁剪后目标更小），细节全开仍在 12 ms 门槛内，满足 ≥30fps 的实时目标。
